# eyxed get 亿云校视频批量下载器
看见牢周录屏27分钟所以做了一个批量下载器
# requirements
- python3.11.3
- requests
# 使用方法
- 使用`editthiscookie`插件复制网页cookie后创建`cookies.json`，粘贴进去
- 运行main.py

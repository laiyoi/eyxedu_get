# eyxed get 亿云校视频批量下载器
看见牢周录屏27分钟所以做了一个批量下载器
# requirements
- python3.11.3
- requests
- python-dotenv
# 使用方法
- 创建`.env`文件，内容为如下登录手机号和密码
```
PHONE_NUMBER=123456789
PASSWORD=114514
```
- 运行main.py
